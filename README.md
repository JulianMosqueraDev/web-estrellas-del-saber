# Colegio Estrellas del Saber

Sitio inicial creado con Astro. El primer módulo es el navbar responsive, basado en `mocks/navbar/navbar.png`.

## Desarrollo con Bun

```sh
bun install
bun run dev
```

## Estructura

- `src/components/atoms/`: piezas visuales reutilizables, como el logo y los iconos.
- `src/modules/navbar/`: módulo del navbar con sus carpetas `services/`, `utils/` y `styles/`.
- `src/layouts/`: estructura compartida de página.
- `src/pages/`: páginas y rutas.
- `src/styles/`: estilos globales.

La configuración de SEO queda pendiente para una etapa posterior.
